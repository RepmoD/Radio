# Retrosheet game data

One file per season, 1934 to 2012, built from the Retrosheet game logs (regular season, postseason and All-Star games) as kept by the Chadwick Baseball Bureau. Ballgame Radio loads a season's file only when it plays or lists a game from that season.

The information used here was obtained free of charge from and is copyrighted by Retrosheet. Interested parties may contact Retrosheet at "www.retrosheet.org".
